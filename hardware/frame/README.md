# Frame

The enclosure for the Device: the standard frame from the upstream build guide ([Part 3: 3D Print Frame](https://transit-tracker.eastsideurbanism.org/docs/build-guide/print-frame)), with its **loose** tolerances. It's printed in two identical halves, so print the same file twice. The halves are not mirror images; one is turned 180° against the other when assembled.

| File | What it is |
| --- | --- |
| `transit-tracker-frame-upright.stl` | **Send this one to print.** Already standing on its solid end (about 30 × 115 mm footprint, 202 mm tall), so it needs no supports. |
| `transit-tracker-frame.stl` | The original as downloaded from Printables, lying flat. |

Print in PLA with no supports and a brim. The rest of the slicer recommendations are in the [build guide](https://transit-tracker.eastsideurbanism.org/docs/build-guide/print-frame#recommendations). Assembly takes 12 × M3 × 8 mm machine screws ([Part 4: Assemble Frame](https://transit-tracker.eastsideurbanism.org/docs/build-guide/assemble-frame)).

The tight-tolerance variant and the STEP sources aren't kept here; get them from Printables if needed.
